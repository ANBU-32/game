# Game

# Introduction


This project is mainly focused on building a basic Rock Paper Scissors game using HTML, CSS, and JavaScript.
The goal is to create a simple interactive game where the user plays against the computer, with real-time results and score updates.


# What This Project Demonstrates


By completing this project, I will have practiced and demonstrated:

-Writing clean and structured HTML

-Designing an attractive user interface using CSS

-Adding interactivity and game logic using JavaScript

-Handling user input and computer-generated choices

-Displaying game results dynamically (win, lose, draw)

-Organizing files into a clear project structure

-Improving familiarity with Git and GitHub through commits and version control

-Building a foundation for future projects involving more advanced JavaScript and UI features
